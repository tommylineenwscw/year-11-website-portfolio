Website Portfolio

Project 1 Overview

This project is a portfolio website that showcases my work and skills in digital technologies. The website is designed to be simple and easy to navigate, with a focus on showcasing my projects and skills. The website is built using HTML, and is hosted on GitHub Pages. The website includes sections for my projects, skills, and contact information.

The website is designed to be responsive, meaning it will look good on all devices, including desktops, tablets, and smartphones. The website is designed to be easy to use, with clear navigation and a simple layout.

Development Process

The development process for this project involved several steps. First, I created a wireframe of the website to plan the layout and design. Next, I wrote the HTML code for the website, including the structure and content. After that, I added CSS to style the website and make it visually appealing. Finally, I tested the website on different devices to ensure it was responsive and worked well on all screen sizes.

End Users

The end users for this portfolio website are potential employers, clients, and anyone interested in my work. The website is designed to showcase my skills and projects in digital technologies, and to provide a way for people to contact me for potential job opportunities or collaborations. The website is also designed to be easy to navigate and visually appealing, making it a good representation of my skills as a web developer.

Wants and Needs:
Some wants and needs for these potential end users include a good layout, easy to use and to see my skills showcased.

Relevant Implications

Described Implications


Social:
How people will interact with my website and whether it’s appropriate and inclusive for a general audience.
Ethical:
Ensuring my website gives credit for any resources I use and respects privacy.
Intellectual Property:
Making sure I use my own work or have permission to use others content (e.g. no stolen images or code).
Usability:
How easy it is for users to find content, navigate, and interact with the website.
Functionality:
Making sure all the links, buttons, and forms work correctly and as expected.
Future-proofing:
Designing the website so it can be updated or expanded easily later.

Explained Implications


Social I used inclusive language and chose a colour scheme that’s comfortable for most users. The site works on both mobile and desktop to reach more people.
Ethical:
I gave credit for any icons or fonts used from online sources. I didn’t collect or store any user data without permission.
Intellectual Property:
All images and text were either made by me or used with permission (Creative Commons or royalty-free sources).
Usability:
The layout is simple and clear. Navigation is the same on every page. I used headings and spacing to help users find content quickly.
Functionality:
I tested all links and forms on multiple browsers. The site works without JavaScript as well, so basic functions still work if JS is turned off.
Future-proofing:
I used clean and well-organized HTML and CSS so I can add new projects or sections later without rebuilding the site.
